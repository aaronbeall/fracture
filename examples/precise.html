Fracture / precision

Fracture with precision and care

Pick an element, pick an impact point, and break it on cue. 

const dialog = useRef<HTMLDialogElement>(null);
const { fracture } = useFracture();

async function destroy(event: React.MouseEvent) {
  await fracture(dialog, { at: event });
  onClose();
}

Source: examples/precise.tsx. Without React: await fracture(element, { at: event }) from @abeall/fracture.
